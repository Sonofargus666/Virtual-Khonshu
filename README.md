# Virtual Khonshu — Thebes Protocol

An Egyptian mythology-inspired animated desktop companion for Windows, with productivity tools and interactive rituals.

## Beta testing

The planned v2.28.17 Moonlit Header beta includes a Pomodoro focus mode, Divine Paperwork animations, Moon Shade desktop mode, and fullscreen support.

Check the [Releases page](https://github.com/Sonofargus666/Virtual-Khonshu/releases) for available test builds and installation instructions. Report bugs through [Issues](https://github.com/Sonofargus666/Virtual-Khonshu/issues). Please remove personal information, chat history, and API keys from any diagnostic logs before sharing.
